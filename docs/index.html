为什么是 Hotview

一颗 Rust 核心，两端原生体验。

Rust 解码核心

image crate 覆盖常见图片格式，FFmpeg 兜底 AVIF / HEIC / JPEG XL；桌面与 Android 共用同一套帧与色彩管线。

wgpu 渲染器

RGBA 与 I420 / NV12 着色器在 GPU 上完成 BT.601/709/2020 色彩矩阵，contain 适配与平移钳制两端行为一致。

硬件解码 + 真声音

Android 走 MediaCodec 视频/音频与 AAudio 无锁输出；桌面走 FFmpeg + swresample + cpal。音频时钟做音画同步。

Material 3 Expressive

Monet 莫奈取色、液态玻璃悬浮底栏、预测性返回、错落进场与弹性动效，界面会呼吸。

处处皆原生

Windows / macOS(arm64 · x86_64) / Linux / Android 五份产物由 CI 自动出包，Android 覆盖 arm64、armv7、x86_64。

本地 · 隐私 · 开源

不联网、不上传。Android 支持系统照片选择器与部分授权，仓库以 Apache-2.0 完全开放。

解码 → 变换 → 上屏

一帧的旅程，全程在 Rust 里。

01

解码

image / FFmpeg / MediaCodec 输出 RGBA 或 YUV 4:2:0 帧，硬件解码优先。

02

色彩变换

GPU 着色器完成矩阵与量程转换，CPU 端仅在必要时做多声道下混与缩放。

03

上屏

wgpu 把纹理合成到 ANativeWindow 或 egui 视图，缩放、平移与分页动效都在 GPU 完成。
